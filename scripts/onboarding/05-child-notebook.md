## What this step does
This step gives each child a dedicated home in your vault so grades, assignments, attendance notes, and summaries all land in a place you can actually use.

## Prerequisites
- Step 1 is complete
- Obsidian is installed
- You can open the local `vault/` folder as an Obsidian vault

## Step-by-step instructions
1. Open Obsidian.
2. Open the `vault/` folder inside this repo as your vault if it is not already open.
3. In the `Students` folder, create one folder per child using a short lowercase name.
4. Copy `vault-template/Students/_template.md` into each child's folder and rename the copy to `index.md`.
5. Open each `index.md` file.
6. Replace `student-name:` with the child's real name.
7. Add any quick notes you want to remember for that child.
8. Save each file.

## AI Prompts
- "Read my family config and create or update [child's name]'s `index.md` page in the vault with a clean student summary."
- "Pull any grades, assignments, or attendance data already available for [child's name] and save it into the new student folder in my vault."
- "Create a starter note for [child's name] in my vault with school name, grade, and sections for grades, assignments, and teacher notes."

## Acceptance criteria
- [ ] Each child has a folder under `vault/Students/`
- [ ] Each child folder contains an `index.md`
- [ ] Each `index.md` uses the child's real name
- [ ] I can open the child pages in Obsidian without errors

## Troubleshooting
- **I cannot find the right vault folder:** In Obsidian, use **Open folder as vault** and pick this repo's `vault/` directory.
- **I do not see `_template.md`:** Make sure you are looking in `vault-template/Students/` from your file browser.
- **I already have notes for a child:** Keep them — just merge the template sections you want.
